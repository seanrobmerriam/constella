Tokens are CSS custom properties declared on `:root` in the `base` layer. Components never hard-code a color, size or duration. They read a token, so changing a token changes every component that uses it.

The tables on this page are read from `base.css` when the docs are built, so they always match the stylesheet.

## Fluid values

Many sizes are fluid: they grow smoothly from a minimum at a narrow viewport to a maximum at a wide one, and stay fixed outside that range. Each fluid token has two inputs in plain pixel numbers, `-min` and `-max`. The token itself is a `clamp()` built from them. To change a fluid size, change its inputs:

```css
:root {
  --space-4-min: 16;
  --space-4-max: 32;
}
```

## Motion

`--hover-*` controls hover transitions. `--open-*` controls opening and closing disclosures, dropdowns, menus and modals. Both are switched off when the visitor asks for reduced motion. Animations stop too, except inside an element with `data-motion="chosen"`, which marks motion the visitor started themselves, such as a [Marquee](/components/marquee/) they pressed play on.
