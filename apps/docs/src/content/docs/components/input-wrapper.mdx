Lays buttons and other controls out in a row that wraps on narrow screens. It only does layout: it adds no validation, no grouping semantics and no label. For related controls that need a group label, use a `<fieldset>`.

## Example

<ComponentExample id="input-wrapper" />

## Markup

```html
<div class="input-wrapper">
  <a class="button_wrap" href="/start">…</a>
  <a class="button_wrap secondary" href="/docs">…</a>
</div>
```

Any controls can go inside: buttons, form fields, a select next to a button. Children are vertically centered and wrap onto new lines with `--space-2` gaps.

## Variants and props

| Astro prop  | HTML equivalent      | Values                     | Default   | Effect                                                                 |
| ----------- | -------------------- | -------------------------- | --------- | ---------------------------------------------------------------------- |
| `marginTop` | `margin-top-*` class | `default`, `0`–`8`, `auto` | `default` | Replaces the default `--space-6` top margin with a spacing-scale step. |
| `render`    | none                 | `true`, `false`            | `true`    | `false` omits the component. It also renders nothing when empty.       |

**Alignment** follows the surrounding layout. The row reads `--_alignment`, so inside a centered container or ContentWrapper the controls center too. Use an `alignment-*` utility on the wrapper to override it.

## States

None. The controls inside keep their own states.

## Accessibility

- It's a plain `<div>` and adds nothing to the accessibility tree.
- Keyboard order follows source order, including after the row wraps. Put controls in the order you want them reached.
- Labels stay attached to their fields when the row wraps. Each field keeps its own `<label>`.

## Behavior

None: native HTML.
