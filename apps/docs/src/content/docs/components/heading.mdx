A heading whose level, which matters for the page outline, is separate from its look. The look comes from any of the ten [text styles](/foundations/typography/). Heading also makes **eyebrows**: the short label above a heading, as a marker or a filled tag.

## Markup

```html
<h2 class="heading text-style-h2">Title</h2>

<!-- An h2 that looks like an h4 -->
<h2 class="heading text-style-h4">Title</h2>

<!-- Eyebrows are paragraphs, not headings -->
<p class="heading eyebrow text-style-small">Label</p>
<p class="heading eyebrow-tag text-style-small">New</p>
```

- `heading` applies the text style's top and bottom margins and the optional line-length limit.
- A paragraph with the `text` class directly after a heading drops its top margin, so the pair stays together. After an eyebrow, it keeps its margin.
- An eyebrow opens its block, such as a ContentWrapper column or a card. The space between it and the heading below is that heading's own top margin. The eyebrow has no margins, so don't place it directly after other content: nothing would separate them.

## Variants and props

| Astro prop | HTML equivalent             | Values                                                                              | Default                | Effect                                                              |
| ---------- | --------------------------- | ----------------------------------------------------------------------------------- | ---------------------- | ------------------------------------------------------------------- |
| `tag`      | the element                 | `h1`–`h6`, `p`, `span`                                                              | `h2`; `p` for eyebrows | The element, and so the level in the outline.                       |
| `variant`  | `text-style-*` class        | `inherit`, `display`, `h1`–`h6`, `large`, `main`, `small`, `eyebrow`, `eyebrow-tag` | the tag's own style    | The look. `p` and `span` default to `inherit`, with no style class. |
| `maxWidth` | `--_mw` in `style`, in `ch` | whole number                                                                        | none                   | Limits the line length in characters.                               |
| `render`   | none                        | `true`, `false`                                                                     | `true`                 | `false` omits the component. It also renders nothing when empty.    |

`eyebrow` adds the `eyebrow` class and the `small` text style: a thin vertical marker before the label. `eyebrow-tag` is a pill in the inverse colors of the current theme. Both render one element; there is no wrapper.

Inside `.heading-accent`, a `<strong>` in the heading takes the theme's accent: a color on dark and brand backgrounds, a yellow highlight on light ones. See [Typography](/foundations/typography/#accent-words).

## States

None.

## Accessibility

- Pick the tag for the page outline: one `h1` per page, then levels in order without skipping. Pick the variant for the look. Never choose a heading level for its size.
- Eyebrows are paragraphs, so they don't appear in the heading outline. Screen readers read the eyebrow, then the heading. If the label matters to the heading's meaning, put it in the heading instead.
- `eyebrow-tag` uses `--text` on `--background`, so its contrast matches the surrounding text.

## Behavior

None: native HTML.
