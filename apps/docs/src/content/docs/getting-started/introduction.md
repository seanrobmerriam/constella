title: Introduction
description: What Constella is and how its parts fit together.
---

Constella is a CSS framework with three related contracts:

- **Styling**: tokens, layers, patterns, component classes, variants and utilities.
- **Markup**: the semantic elements, classes and attributes each component needs.
- **Behavior**: native interaction, plus optional TypeScript enhancements that you initialize and clean up yourself.

The reference site is built with Astro, but the CSS and the examples in these docs do not need Astro.

Every example on a component page shows the same content in two tabs: **HTML / CSS** (selected first) and **React TSX**. A short list under each example names the stylesheet and any behavior it needs.
