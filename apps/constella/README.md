# Constella

A customizable CSS framework with typed component props, expanding compatibility
across Astro, SolidStart, TanStack Start, React, and plain HTML. This package
contains the Astro site and component examples.

## Getting started

Run from the monorepo root:

```sh
bun install
bun run dev:site
```

Use `bun run build:site` to build and `bun run check` to type-check the workspace.
Set `PUBLIC_SITE_URL` to the deployed site origin for canonical URLs and the sitemap.

## Documentation

Documentation lives in [the docs app](../docs). Run `bun run dev:docs` from the
monorepo root to view it at <http://localhost:4322>.
Project conventions live in [CONSTELLA.md](CONSTELLA.md).
